# Preserved replacement knowledge checks

An administrator can request a replacement multiple-choice knowledge check for a saved original lesson. The existing revision endpoint accepts `new_check` and creates a new owned course with one missing lesson. Other saved lessons are copied unreviewed. The original teaching sections, course and scored evidence remain available. Curated courses and ordinary/Premium users remain excluded by the existing beta and institution gates.

One bounded worker call receives the saved five teaching sections, objective, request preferences and earlier question texts. It does not receive account identity, stored student records, scored responses or earlier answer keys. The resulting object must satisfy the same bounded quiz schema as other lessons. Teaching sections are copied from the source rather than taken from the model response. Unknown generated fields are discarded. Long teaching material or question history can exceed the conservative input-byte-plus-output reservation; that failure occurs before spending and preserves the other lessons. Monthly counters, retries, leases, cancellation and in-flight policy rechecks reuse the existing worker.

The worker resolves at most24 owner-scoped ancestor courses, refuses cycles/missing source lessons, and rejects questions matching any ancestor after whitespace normalization and case folding. This catches exact repetitions and option rearrangements with an unchanged question. It does not prove semantic novelty, factual accuracy or appropriate difficulty. The prompt asks for a different example and human review must verify alignment, correctness and an unambiguous answer. The revised course needs a new accuracy review before scoring. Builder results remain assisted evaluation evidence, and each item can be scored once.

The browser serializes replacement requests with other workspace mutations, reports refusals without losing the selected course, and prevents interaction with previous course controls during loading. Failed selections retain the previous draft and usable controls. Late responses/errors cannot replace the current course or status. Deferred-response assertions exercise replacement refusal, locked edit/regeneration actions, failed selection and subsequent draft-save refusal.
