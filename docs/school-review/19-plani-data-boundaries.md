# Plani account-data and internal-operation boundaries

The prior route-level tutor gate did not govern every internal Plani tool. The account snapshot also attached stored workload, memories and study history without the existing AI-personalization opt-in. This continuation repairs specific server-side boundaries; it does not establish complete application policy coverage or school readiness.

## Implemented behavior

- Every internal tool resolves the actual signed-in owner, rechecks tutor/assessment policy, and checks its scheduler, study, upload or named connection capability. Supplying another account ID cannot select that account. Unknown or malformed arguments cannot grant access.
- Automatic account context and matching-note retrieval require AI-personalization consent. Stored-account read tools also require it. Explicit new task/note input and fixed navigation/connection links remain available under their capability policies. The assistant prompt describes conditional access and distinguishes missing context from an empty account.
- Scheduler, notes and study/review sections are omitted when restricted. Aggregated grades, saved schedules and Command Center summaries lack sufficient source provenance to separate restricted input safely; Plani conservatively omits those aggregates when a mapped LMS/calendar source is restricted. Manual task reads and permitted local scheduling remain available.
- Profile extras resolve `UserIdentity.user_id`, rather than treating a user ID as the identity table's primary key. A regression constructs real conflicting primary-key/owner records and verifies another student's profile is not attached.
- Nested schedule generation pins policy/consent before gathering data and compares it before/after the provider and after placement, before persistence. Revoked scheduler, consent, provider or source access prevents saving the generated schedule/archive. Calendar denial preserves allowed local scheduling, class/manual planning and saved results while skipping calendar credentials/export. The actual placement helper and its request memo obey calendar policy.
- The agent pins consent/policy for assembled prompts and checks before and after each model response, including its final fallback. A changed state ends the request before further tools, provider calls or a context-derived reply. Every additional model round, nested schedule call and final fallback receives an AI-firewall allowance; responses are recorded. Final provider failure is reported as a failure, with actual completed action results retained.
- Dense note embeddings require the actual owner's consent, upload/study capability and permitted Gemini processing, including in background calls. Batches and responses recheck permission. Denial uses the existing local lexical retrieval path. Existing Gemini contractual/configuration gates still apply; no flags were enabled and no provider was contacted by these tests.
- The shared LMS collector checks the actual owner's source policy before cache access and credential opening, then filters revoked mapped-source rows before return/cache. Restricted partial fetches cannot seed an unrestricted cache. The legacy unified-task route also enforces its active source, including calendar feeds. Grade personalization checks consent, mapped source policy and provider permission before credential lookup.
- Institution and feature-flag reads refresh already-loaded records when policy is re-evaluated; invalidating the request decision cache alone could otherwise retain stale ORM policy state.

Access checks cannot recall an already-started external request or undo an event already written by a provider. This checkpoint checks at operation boundaries; transactional production concurrency and live vendor behavior remain unverified. At this checkpoint, the shared collector still included legacy providers outside the mapped Canvas/StudentVUE/calendar registry. The subsequent [LMS continuation](20-lms-policy-boundaries.md) adds seven named sources and additional guarded paths; universal policy coverage remains incomplete.
