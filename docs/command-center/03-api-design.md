# Phase 3 — API Design

Two new endpoints. Both authenticated (flask-login session OR `Authorization: Bearer <ExtensionToken>`).

## `GET /api/today`

Returns the complete Command Center payload in one round-trip.

**Behavior:**
- Reads `BriefingCache`. If `expires_at` is in the past or `payload_hash` no longer matches a freshly built `TodayPayload`, refresh inline (≤1 AI call) before responding. Otherwise serve cached.
- Idempotent. Safe to poll. Rate-limited by `flask-limiter` to 30 req/min per user (refresh button + pull-to-refresh).

## `GET /api/today/explain?component=priority&task_id=<id>`

Returns the structured rationale for a single score on the page. Powers the "why?" hover/tap.

**Query params:**
- `component`: one of `priority` | `health` | `forecast`.
- `task_id`: required when `component=priority`.

**Response:**

```jsonc
{
  "component": "priority",
  "score": 92,
  "rationale": [/* same shape as plan[].priority.rationale */],
  "narrative": "This is the highest priority because the exam is in 2 days and the packet is required to prepare for it."
}
```

`narrative` is generated by the Narrator only on first request per (user, score) and cached in-memory for 5 minutes. Not durably cached — explanations are read-mostly UI candy, not critical path.

## `POST /api/today/refresh`

Forces a briefing rebuild. Used by the pull-to-refresh gesture and by the cron sweeper.

- Body empty.
- Rate-limited 6 req/hour per user (it costs an AI call).
- Returns the same payload as `/api/today`.

## `POST /cron/refresh-briefings`

Internal cron poke (already-established pattern, see `/cron/send-reminders`). Authenticated by `X-Cron-Token` matching `CRON_TOKEN` env. Iterates users with `expires_at < now()` and rebuilds in batches.

Recommended Railway schedule: every 30 minutes.

## Authentication & rate limiting

- All endpoints honor the existing `is_logged_in()` helper plus the extension JWT path (`load_user_from_request`).
- All endpoints exempt from the global default limit; explicit per-route limits as above.
- `/cron/refresh-briefings` is `_default_limit_exempt()` and gated by `CRON_TOKEN`.

## Versioning

`meta.schema_version = 1`. The extension and any future native client should send `Accept: application/vnd.intelliplan.today.v1+json` once we add a v2. Out of scope for MVP.

## What we do *not* add

- No `/api/today/dismiss`, `/api/today/complete` — those reuse the existing `/dismiss`, `/feedback/complete`, `/tasks/manual/update` endpoints. The Command Center is a *read* surface that links into existing write surfaces.
- No GraphQL.
- No SSE/WebSocket. The page is polled; pull-to-refresh covers the rare case the student wants live update.
