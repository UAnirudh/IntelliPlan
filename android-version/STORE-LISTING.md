# Store listing draft

## App name

IntelliPlan

## Short description

An adaptive study planner that turns assignments into a clear plan.

## Full description draft

IntelliPlan brings assignments, grades, schedules, focus sessions, and an AI
tutor into one calm study workspace. Connect supported school platforms, add
your own tasks, and get a practical plan for what to do next.

Features include Today priorities, custom tasks, adaptive plans, Canvas and
other school connections, Google Calendar availability, grades and learning
insights, focus sessions, Plani AI tutoring, optional photo-based problem
solving, offline-friendly task changes, and light/dark/system themes.

IntelliPlan is a study organization tool. It does not replace a teacher,
school, academic advisor, or medical professional.
