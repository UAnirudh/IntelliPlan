How GPA is calculated

Each letter grade is worth points (A = 4.0, B = 3.0, C = 2.0, D = 1.0, F = 0). Multiply each class's points by its credit hours, add them all up, and divide by the total credits. On a weighted scale, harder classes get a bonus — usually +1.0 for AP/IB and +0.5 for Honors.
