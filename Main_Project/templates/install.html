Install IntelliPlan

Use IntelliPlan from your mobile browser or install it as a web app

  1. Open https://intelliplan.tech in Chrome
  2. Tap the browser menu
  3. Choose Add to Home screen or Install app
  4. Open IntelliPlan from your home screen
{# This page is about installing the web app to a home screen. Someone who landed here wanting a real application for their laptop should not have to find /download by guessing. #}

On a computer? There's a proper desktop app for Windows, macOS and Linux — native reminders and a tray shortcut.
