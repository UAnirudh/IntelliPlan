Before you install

These builds are not code-signed. Windows SmartScreen will show a warning — choose More info, then Run anyway. macOS Gatekeeper will refuse the first launch — right-click the app and choose Open.

That is what an unsigned build looks like, not a sign the download is broken. Signing certificates are a running cost this project does not currently carry.
